# 🎵 V01 - Interactiva

Instalação interativa com tracking 3D de mãos e face.

## [▶️ Demo Online](https://rodrigobrazao.github.io/trama-experiencias/v01-interactiva/)

## Features
- 🎹 5 instrumentos (Piano, Violoncelo, Trompete, Contrabaixo, Bateria)
- 👁️ Face Mesh 3D (468 landmarks)
- ✋ Hand tracking com profundidade Z
- 🎨 Grid elástica com distorção em tempo real

## Stack
MediaPipe Hands + Face Mesh • Web Audio API • Canvas 2D
